# AI 泡沫監控儀表板

用公開數據監測 AI 投資是否過熱的自動化儀表板。框架：中金《如何監測AI泡沫？》(2026-07)
四維體系的修正版——六維 21 指標，門檻錨定 2000 年網路泡沫類比值。

- **量化指標**：GitHub Actions 於每個交易日結束後（台北時間清晨）自動抓取
  FRED、Stooq、SEC EDGAR、multpl、SlickCharts 重算並提交 `data.json`。
- **質化指標**（VC 集中度、循環融資、敘事熱度等）：每週由 Claude 覆核更新。
- 任一來源抓取失敗時保留舊值並標註「資料延遲」，絕不編造數字。

資料與方法論詳見網站內「方法論與更新」分頁。本專案為研究監測工具，不構成投資建議。
